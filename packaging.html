Packaging and Installation

1. CMake Integration

ParaView binaries ship with their own embedded MPI runtime. If you compile pydpvz against a different MPI library, you will encounter ABI crashes.

Find the correct MPI version: Use the dpvtkmpiinfo.py utility to inspect your pvbatch binary:

python3 scripts/dpvtkmpiinfo.py ./paraview_v610/bin/pvbatch

This script will output the recommended CMAKE_PREFIX_PATH that must be provided to CMake (or setup.py) to ensure absolute ABI compatibility.

2. Spack Packaging

The py-dpvz package can be installed cleanly into an existing Spack environment containing ParaView.

Adding the Custom Repository:

  1. Ensure the custom repository (located at spack-repo/) is available.

  2. Add it to your Spack configuration:

    spack repo add ./spack-repo

  3. Install the library:

    spack install py-dpvz

If you are using an external MPI (not managed by Spack), paste the YAML snippet generated by dpvtkmpiinfo.py into your spack.yaml packages: section under externals: before running spack install.
